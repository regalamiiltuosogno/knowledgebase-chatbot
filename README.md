# knowledgebase-chatbot

Questo repository contiene le pagine web pubbliche che costituiscono la base di conoscenza del chatbot di assistenza di regalamiiltuosogno.

Le pagine vengono pubblicate in automatico con GitHub Pages e lette dal chatbot tramite i rispettivi indirizzi pubblici. I file presenti qui sono generati e aggiornati da un processo automatico: **non vanno modificati a mano**.

## Contenuto

- `index.html`: indice delle pagine pubblicate.
- `sitemap.xml`: elenco degli indirizzi delle pagine.
- `pages/`: le pagine della knowledge base.

## Documentazione

La documentazione completa del processo (funzionamento, istruzioni operative, manutenzione e risoluzione dei problemi) è disponibile nella **wiki di regalamiiltuosogno**.

L'accesso è riservato al personale autorizzato.
